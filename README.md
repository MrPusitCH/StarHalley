# StarHalley

ฉากท้องฟ้ายามค่ำคืนกับดาวหางฮัลเลย์ที่เคลื่อนไหวตามจังหวะเพลง สร้างด้วย Next.js — intro โดย Pma.Dev

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## ไฟล์เพลง

ไฟล์เพลงไม่ได้รวมอยู่ใน repo (ติดลิขสิทธิ์) — วางไฟล์ของคุณเองไว้ที่ `public/music/halley.mp3`
แล้วเพลงจะเริ่มเล่นทันทีเมื่อกดเข้าจากหน้า intro
